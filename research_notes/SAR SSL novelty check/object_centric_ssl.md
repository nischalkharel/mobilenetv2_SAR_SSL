# Object-centric, region-based and saliency-guided view selection in joint-embedding SSL (natural images, detection pretraining)

Scope note: this file covers natural-image / detection-pretraining work only (SAR and remote-sensing SSL is another researcher's scope, except DINO-MC which is included because it is a crop-SIZE study). Sources are primary (arXiv / ar5iv full text, CVF) unless marked. Years are the arXiv first-version year. "Random control" below always means: did the paper compare its object/saliency placement against randomly placed crops OF THE SAME SIZE. Papers are sorted inside each question by relevance to our finding (RegionDINO: label-free bright-region crops for DINO on SAR scenes, MobileNetV2, +9.4 at 1 % labels on cross-dataset object chips; random-window control gets part of the gain; keeping the whole-scene views loses most of it; crop size matters up to ~half the image; placement matters only for the object-chip downstream task, not for same-dataset detection).

## KQ1. Which papers place SSL views on object proposals, saliency or segments, and what did each show?

### Takeaway
At least 14 papers (2020-2025) move or constrain the crops of a joint-embedding method toward objects using label-free proposers (BING, selective search, unsupervised saliency, the network's own activation map, Normalized-Cut on its own features, k-means), almost all with ResNet-50 and almost all evaluated on COCO/VOC detection or ImageNet/VOC linear probes; typical gains are +0.3 to +3 AP for detection and +1 to +9 points for linear classification on scene-centric data, and the largest gains always appear when the pretraining data is scene-centric (OpenImages, COCO) rather than ImageNet. A second family (DetCon, Odin, ReSim, SlotCon, SelfPatch, Leopart, Self-EMD, OCEBO) keeps DINO/BYOL-style random crops unchanged and only groups the FEATURE MAP into regions, so they are not crop-placement methods. Only four papers report any random-placement comparison (SoCo, Coarse-Is-Better, UniVIP's "naive" boxes, ContrastiveCrop's k=0/alpha=1), and none of them matched crop size and placement in a full factorial design.

### Cited Findings

Family A: papers that change WHERE the crops are cut (closest to our method)

- Object-Aware Cropping (Mishra et al., 2021; TMLR 2022). Proposer: BING (label-free in the sense that it uses no class labels; trained on class-agnostic boxes of 2,501 VOC images); Edge-Boxes and an unsupervised proposer (Vo et al. 2019) "performed similarly". Up to 10 proposals per image, one drawn uniformly at random. Backbone ResNet-50; applied to MoCo-v2, BYOL, Dense-CL. OpenImages classification mAP (MoCo-v2): Scene-Scene 49.8, Obj-Obj+Dilate 58.6, Obj-Scene 58.1, Obj-Obj+Shift 54.1; BYOL: 50.2 vs 59.1 (Obj-Obj+Dilate) / 58.5 (Obj-Scene); with ground-truth boxes 60.2 (Obj-Obj+Dilate). Dilation ablation (VOC AP): delta=0 54.3, 0.1 55.1, 0.2 54.5, 0.3 54.2. On ImageNet pretraining the gain shrinks to +0.5 top-1 (67.5 -> 68.0) and +0.4 COCO AP (39.8 -> 40.2). Random-placement control with proposal-sized boxes: NOT reported. Crop scale: object crops use a lower bound s_min = 0.2 / (average BING proposal size) because the default 0.2 "results in extremely small crops". — [arXiv 2112.00319 (HTML v1)](https://arxiv.org/html/2112.00319v1)
- Same paper, abstract-level claim: +8.8 % mAP over random scene-level cropping on OpenImages with MoCo-v2. — [arXiv abs 2112.00319](https://arxiv.org/abs/2112.00319)

- ContrastiveCrop (Peng et al., CVPR 2022 oral). Proposer: the model's OWN last-conv feature map summed over channels, normalized, thresholded at k=0.1, bounding box = rectangular closure; label-free; box updated every 20 % of training. Center-suppressed sampling: crop centre ~ Beta(0.6,0.6) inside the box. Backbone ResNet-18 (small sets) / ResNet-50 (ImageNet). Linear eval, RandomCrop -> ContrastiveCrop: SimCLR CIFAR-10 89.63 -> 90.08, CIFAR-100 60.30 -> 61.91, Tiny-IN 45.19 -> 46.21, STL-10 88.95 -> 89.53; MoCo 86.73 -> 88.78 / 56.10 -> 57.65 / 47.09 -> 47.98 / 89.17 -> 89.81; BYOL 91.96 -> 92.54 / 63.75 -> 64.62 / 46.08 -> 47.23 / 91.84 -> 92.42; SimSiam 90.96 -> 91.48 / 64.79 -> 65.82 / 43.03 -> 44.54 / 89.39 -> 89.83. Size control: Algorithm 1 reuses the same scale s and ratio r as RandomCrop, so ONLY the centre placement changes; k=0 (RandomCrop) and alpha=1 (uniform inside box) are the controls; no separately labelled same-size random-box control. — [ar5iv 2202.03278](https://ar5iv.labs.arxiv.org/html/2202.03278)
- CAST (Selvaraju et al., CVPR 2021). Proposer: Deep-USPS unsupervised saliency (no human saliency labels). Rule: each crop must cover at least phi times the total salient area (phi=0 recovers MoCo random crops; default phi=0.2). Backbone ResNet-50-style (conv5 7x7x2048). COCO-pretrained MoCo: VOC07 linear 66.9, IN-1k 46.5, VOC det AP 47.5; + constrained crops only: 69.3 / 46.0 / 49.0; + full CAST (adds Grad-CAM attention loss): 73.1 / 48.7 / 54.2. So saliency-constrained cropping alone gives +2.4 VOC07, +1.5 VOC det AP, and -0.5 IN-1k. Random-placement control with matched sizes: NOT reported (phi=0 is unconstrained random crop). — [ar5iv 2012.04630](https://ar5iv.labs.arxiv.org/html/2012.04630); CVF copy [here](https://openaccess.thecvf.com/content/CVPR2021/papers/Selvaraju_CASTing_Your_Model_Learning_To_Localize_Improves_Self-Supervised_Representations_CVPR_2021_paper.pdf) (403 on fetch).
- SoCo (Wei et al., NeurIPS 2021 spotlight). Proposer: selective search (scale=500, sigma=0.9, min_size=10), boxes kept if 1/3 <= w/h <= 3 and 0.3 <= sqrt(wh)/sqrt(WH) <= 0.8, K=4 proposals per image; label-free. Views: V1 = whole image at 224, V2 = random crop of V1 with scale [0.5,1] resized to 224, V3 = V2 downsampled to 112; box jitter r in [-0.1,0.1]. Backbone ResNet-50-FPN pretrained with the Mask R-CNN head structure. COCO Mask R-CNN R50-FPN 1x APbb/APmk: supervised 38.9/35.4, MoCo-v2 40.4/36.4, DenseCL 40.3/36.4, InsLoc 400 ep 42.0/37.6, SoCo 100 ep 42.3/37.6, SoCo 400 ep 43.0/38.2, SoCo* 43.2/38.4. Random boxes replacing selective search: YES tested: K=1 random boxes 41.4/36.9 vs K=1 selective search 41.6/37.3; K=4 and K=8 random boxes diverged (NaN). Whole-image view retained (V1). — [ar5iv 2106.02637](https://ar5iv.labs.arxiv.org/html/2106.02637)
- ORL (Xie et al., NeurIPS 2021). Pipeline: BYOL image-level pretraining -> selective search top-100 RoIs + K=10 nearest-neighbour images + RoI correspondence -> object-level BYOL with intra- and inter-image RoI losses; RoI patches 96x96; label-free. ResNet-50, 800 ep on COCO. BYOL -> ORL: VOC07 SVM 84.5 -> 86.7 (supervised IN 87.5), ImageNet linear 57.8 -> 59.0, Places205 50.5 -> 52.7 (supervised 51.5), COCO det APbb 39.5 -> 40.3 (supervised 39.7), APmk 35.6 -> 36.3. Random boxes vs selective search: NOT in the paper; closest is ground-truth COCO boxes 85.4 vs selective search 86.7 (GT boxes were WORSE). Multi-crop BYOL control 84.0 vs ORL 86.7. Object-view jitter: centre shift within 50 % of box, area 50-200 % of box, aspect 1/2-2. — [ar5iv 2106.11952](https://ar5iv.labs.arxiv.org/html/2106.11952)
- UniVIP (Li et al., CVPR 2022). Proposer: selective search (min scale 64 px, aspect 1/3-3, max IoU 0.5); two overlapping scene crops must share K=4 instances (up to 20 retries); instances cropped to 96x96; label-free; ResNet-50, BYOL-style. ImageNet linear (COCO 800 ep): BYOL 57.8, ORL 59.0, UniVIP 60.2; COCO+: 59.6 / 60.7 / 63.0. COCO det APbb/APmk (COCO pretrain): BYOL 39.5/35.6, ORL 40.3/36.3, UniVIP 40.8/36.8. Controls (Table 8b, IN top-1 / COCO mAP): no instance views 57.7/39.6; "naive" (heuristically generated) boxes 58.9/40.5; selective search 60.2/40.8; ground-truth COCO boxes 58.5/40.3 (again GT worse than selective search); random (non-overlapping) scene views instead of overlapping 59.3/40.3. No purely random-box ablation. — [ar5iv 2203.06965](https://ar5iv.labs.arxiv.org/html/2203.06965)
- InsLoc (Yang et al., CVPR 2021). Views: an image crop (foreground) is pasted onto a different background image at a random position with random scale 128-256 px and aspect [1/2,2] (FPN) or [1/3,3] (C4); the two views of one instance use different backgrounds; label-free; ResNet-50. COCO Mask R-CNN R50-FPN 2x: supervised 41.6/37.6, MoCo-v2 200 ep 41.7/37.6, InsLoc 200 ep 43.2/38.7, 400 ep 43.3/38.8. Ablations on foreground size or placement: NONE. — [ar5iv 2102.08318](https://ar5iv.labs.arxiv.org/html/2102.08318)
- SGCL, Saliency Guided Contrastive Learning on Scene Images (Chen et al., 2023). Saliency comes from the model ITSELF: Normalized Cut on the cosine self-similarity graph of its own feature map (second-smallest eigenvector), thresholded at the mean, connected components -> boxes, t=4 regions sampled proportional to saliency, refreshed every 100 epochs; label-free; crops 8-100 % of the box, resized to 96x96; ResNet-50, COCO 800 ep. COCO det APbb / APmk / IN linear / VOC07 SVM: BYOL 39.5/35.6/57.8/84.5, ORL 40.3/36.3/59.0/86.7, SGCL 40.7/36.6/59.9/86.9; COCO+: BYOL 40.0/36.2/59.6/87.0, ORL 40.6/36.7/60.7/88.6, SGCL 41.3/37.1/61.8/89.0. Crop-source ablation (VOC07, 100 ep): selective search 80.3, SGCL saliency 83.2, GT boxes 84.7; saliency methods RBD 79.6, NF 81.9, QE 82.1, SGCL 83.2. Random-crop control: NOT labelled (BYOL baseline 76.9 is the proxy). Pairs are built only from saliency regions; the paper does not say whether whole-image views are kept. — [ar5iv 2302.11461](https://ar5iv.labs.arxiv.org/html/2302.11461)
- Coarse Is Better? (Zhu, He, Wu, 2023). Pipeline: sum the channels of an SSL backbone's feature map (SCDA objectness), score 12 anchors per location (sizes 32/64/128/256 x aspect 0.5/1/2), NMS, keep top 5 boxes; then train a FRESH backbone with plain MoCo-v2 / BYOL / DenseCL / MAE where BOTH views come from the same crop; label-free; ResNet-50 (ViT-B for MAE); COCO 400 ep. VOC2007-pretraining controls (BYOL; objectness %, det AP50, finetune mAP, linear mAP): Image-Crop 36.4 %, 63.3, 63.0, 39.8; GT-Crop 100 %, 66.9, 69.2, 33.1; Grid-Crop 39.8 %, 68.1, 70.3, 41.6; Poor-Crop 20.1 %, 60.4, 62.2, 21.4; GTpad-Crop 48.2 %, 69.7, 72.3, 40.2; Our-Crop 52.6 %, 69.5, 70.7, 42.5. - ODIS, Object-level Self-Distillation (Hizli, Yildiz, Marttinen, June 2025, arXiv preprint). - Revisiting Contrastive Methods (Van Gansbeke et al., NeurIPS 2021). ### Inferences
- Nothing in this inventory cuts DINO views around a pixel-intensity rule; every proposer is either a learned/engineered objectness model (BING, selective search, Deep-USPS, RBD), the network's own activations (ContrastiveCrop, SGCL, Coarse-Is-Better, Leopart), or ground truth (ODIS, Purushwalkam, ablations in ORL/UniVIP/SGCL/Coarse-Is-Better). A brightness rule is in spirit closest to RBD-style hand-crafted saliency (used in DiLo and as an SGCL ablation at 79.6 vs 83.2).
- Three independent papers (ORL 85.4 vs 86.7; UniVIP 58.5 vs 60.2; Coarse-Is-Better GT 66.9 vs Grid 68.1 / Ours 69.5) found that tight GROUND-TRUTH boxes are WORSE than loose, label-free proposals, and ODIS (2025) found random context-rich local crops beat object-aware windows. This supports the view that "object-ish but loose" placement, not precise object boxes, is what helps.
- The gains in Family A are much larger on scene-centric pretraining data (OpenImages +8.8 mAP, COCO +1.5 to +3 AP) than on ImageNet (+0.3 to +0.5), consistent with our SAR scenes (very scene-centric: small targets in large clutter) showing a large effect.

## KQ2. Which papers study the effect of crop SIZE / scale in multi-crop SSL, and what did they find?

### Takeaway
Crop-scale sweeps exist in DINO, InfoMin ("What makes for good views"), a 2023 low-compute study with MobileNetV2, a 2024 SimSiam overlap/patch study, MultiSiam, DenseDINO and a 2026 DINO-style global-scale sweep; they consistently find an inverted-U with the optimum lower bound somewhere between 0.2 and 0.4 of image area for classification, while dense/correspondence tasks prefer LARGER global crops (0.6-0.72) and, for ViTs, small local crops can even hurt segmentation. No paper in this set sweeps crop size on an object-chip transfer task or ties the optimum to the physical size of the objects in the scene.

### Cited Findings
- DINO (Caron et al., ICCV 2021), ViT-S/16, 300 ep, kNN top-1 as a function of the local/global split s (locals (0.05, s), globals (s, 1)): s=0.08 65.6, 0.16 68.0, 0.24 69.7, 0.32 69.8, 0.48 69.5; optimum near s ~ 0.3 vs 0.14 used by SwAV. Multi-crop table (linear top-1, 100/300 ep): 2x224 only 67.8/72.5; +2x96 71.5/74.5; +6x96 73.8/75.9; +10x96 74.6/76.1. Multi-crop helps DINO most (+3.4 linear) and HURTS BYOL (71.4 -> 64.8 linear). — [ar5iv 2104.14294](https://ar5iv.labs.arxiv.org/html/2104.14294)
- What Makes for Good Views (Tian et al., NeurIPS 2020): RandomResizedCrop(scale=(c,1)) sweep under MoCo (100 ep): reverse-U with the sweet spot at c=0.2; the supervised default 0.08 "can drop accuracy by more than 1 %" with an MLP head. Spatial-distance experiment: two 64x64 patches at offset d (64-384 px) on DIV2K, tiny AlexNet, linear eval on STL-10/CIFAR-10: reverse-U with sweet spot d=128 (values only in figure). — [ar5iv 2005.10243](https://ar5iv.labs.arxiv.org/html/2005.10243)
- Effective SSL on Low-compute Networks without Distillation (Tan, Saleh, Martinez, ICLR 2023), MobileNetV2 / ResNet-18/34/50 / ViT-Ti/S: DINO default global (0.14,1), local (0.05,0.14) is sub-optimal for small nets; "the best results come from setting both scales within [0.3, 0.4]"; local crop resolution should scale with pixel scale (103 px at S=0.14, 128 px at S=0.3); re-weighting global/local loss best at alpha 0.3-0.4; more local views saturate quickly. ImageNet linear (small net): DINO 66.2 -> new crop scales 67.0 -> +pixel scale 67.9 -> final 68.3. — [ar5iv 2210.02808](https://ar5iv.labs.arxiv.org/html/2210.02808)
- Two Global Crops Suffice (Sunagad, Jesslen, Kortylewski, arXiv 23 Sep 2026), ViT-L/16, IN-1k 100 ep: random global scale [s_min,1]: kNN peaks at s_min=0.24 (71.75), semantic PCK peaks at 0.60, geometric recall at 0.32; fixed scale [s,s]: kNN/linear peak at s=0.40 (69.97/71.19), semantic PCK at 0.60, geometric at 0.72; "classification peaks at s=0.40 while correspondence and dense downstream tasks peak at s=0.60-0.72". Local-crop scale and placement are NOT varied separately; no detection evaluation. — [arXiv 2609.28187](https://arxiv.org/html/2609.28187v1)
- Analysis of Spatial Augmentation in SSL (Jha & Tuytelaars, Sept 2024), SimSiam ResNet-50 on CIFAR/STL-10/ImageNet-100: overlap fraction gives an inverted-U; in the "patch" setting (full image vs fixed-size patch), patch area 0.2-0.4 is best and 0.1 or >= 0.6 is worse; the paper does not separate size from placement (overlap setting varies both together; patch location is not a controlled factor). Numbers only in figures. — [arXiv 2409.18228](https://arxiv.org/html/2409.18228)
- MultiSiam (ICCV 2021), driving scenes, ResNet-50: minimum crop scale 0.08 gives 71.9 Cityscapes mIoU vs 71.7 at 0.2; authors conclude a smaller minimum is "more beneficial" for scale invariance. — [ar5iv 2108.12178](https://ar5iv.labs.arxiv.org/html/2108.12178)
- DenseDINO (IJCAI 2023), ViT-Tiny, IN 100 ep, kNN cls / VOC linear seg: 2x224 no local 53.3 / 46.0; 2x224 + 4x96 local 58.8 / 39.7; 6x224 globals 56.7 / 46.4. Local views raise classification but cut segmentation by ~6 mIoU; attributed to "object misalignment between views". — [ar5iv 2306.04654](https://ar5iv.labs.arxiv.org/html/2306.04654)
- DINO-MC (Wanyan et al., 2023, Sentinel-2 remote sensing, SeCo-100K): replaces DINO's fixed 96 px locals with six sizes (184/164/144/124/104/84 px, scale (0.05,0.32)), motivated by "limited variation in object size observed in remote sensing imagery"; EuroSAT linear: ResNet-50 89.65 -> 95.59, WRN-50-2 91.65 -> 95.70, ViT-S 91.50 -> 94.09, Swin-T 86.87 -> 90.54; BigEarthNet 10 %/100 % (ResNet-50) 79.67/85.38 -> 82.55/86.86; OSCD F1 49.53 -> 52.46. NO ablation over local crop size and no detection. — [ar5iv 2303.06670](https://ar5iv.labs.arxiv.org/html/2303.06670)
- Object-Aware Cropping: Table 11 sweeps the lower scale bound for object-scene crops with the peak at 0.2 (58.1 OpenImages mAP); for object crops the lower bound is rescaled by proposal size. — [arXiv 2112.00319 (HTML)](https://arxiv.org/html/2112.00319v1)
- SoCo filters proposals to 0.3 <= sqrt(wh)/sqrt(WH) <= 0.8 (i.e. object views between 9 % and 64 % of image area) and crops V2 at scale [0.5,1]; K=1/4/8/16 proposals give 41.6/42.3/41.6/41.2 APbb. — [ar5iv 2106.02637](https://ar5iv.labs.arxiv.org/html/2106.02637)
- RoB "Simple Recipe for Low-compute SSL" (Duval, Misra, Ballas, 2023): removing multi-crop from a DINO-S/8-distilled student lowers IN top-1 71.4 -> 70.4 and iNat18 39.8 -> 35.4; no crop-scale sweep. — [ar5iv 2301.09451](https://ar5iv.labs.arxiv.org/html/2301.09451)
- Van Gansbeke et al.: crop ranges (large 20-100 %, small 5-14 %) are fixed design choices, not ablated. — [ar5iv 2106.05967](https://ar5iv.labs.arxiv.org/html/2106.05967)

### Inferences
- Across DINO (s ~ 0.3), InfoMin (c = 0.2), Tan et al. ([0.3,0.4] for MobileNetV2), Jha & Tuytelaars (0.2-0.4 patch area) and Two Global Crops (0.40 fixed), the classification-optimal crop lower bound is ~0.2-0.4 of image area, i.e. "up to about half the image" is in line with prior work; our "crop size matters up to ~half the image" finding on SAR is therefore not novel in direction, but none of these sweeps was run on object-chip transfer or on a brightness-placed crop.
- Tan et al. is the only crop-scale study on MobileNetV2 and reports the same optimum band; it is the most direct precedent for a MobileNetV2-specific crop-scale claim.

### Gaps
- No paper found that links the optimal crop size to the physical object size in the scene (searched "crop size matters self-supervised", "local crop scale range ablation 2024 2025", "crop scale self-supervised study"); DINO-MC motivates multi-size locals by object-size variation but does not ablate size.
- No crop-scale sweep found on a cross-dataset object-chip (classification-on-crops) downstream task.

## KQ3. Did any paper show that DROPPING the global whole-image views and training only on small object-sized views helps transfer, or the opposite?

### Takeaway
Both directions are documented, and the outcome depends on the downstream task. Coarse-Is-Better (train only on pseudo-object crops, no whole-image view) beats whole-image BYOL on VOC/COCO detection, Mishra's two-object-crop variant beats the object+scene variant on OpenImages and COCO detection, and Purushwalkam & Gupta's box-only MoCo beats full-image MoCo on CROPPED-box evaluation while losing 4.8 mAP on full-image VOC; conversely, removing local crops or globals in DINO-style ViT training costs 5-7 kNN points (DINO, Two Global Crops) and replacing globals by locals collapses correspondence.

### Cited Findings
- Coarse Is Better? trains a fresh ResNet-50 with plain BYOL/MoCo-v2 ONLY on the top-5 pseudo-object crops (both views from the same crop; whole-image "Image-Crop" is only the baseline): VOC det AP50 63.3 (Image-Crop) -> 69.5 (Our-Crop), finetune mAP 63.0 -> 70.7, linear 39.8 -> 42.5; COCO APbb 38.8 -> 40.2. — [ar5iv 2306.04244](https://ar5iv.labs.arxiv.org/html/2306.04244)
- Object-Aware Cropping: Obj-Obj+Dilate (two object crops, no scene crop) 58.6 OpenImages mAP vs Obj-Scene 58.1 vs Scene-Scene 49.8; COCO det 39.7 vs 39.4 vs 38.2; VOC det 55.0 vs 54.2 vs 51.8; but undilated Obj-Obj (delta=0) drops to 54.3 VOC AP and the v1 text says purely object crops and purely scene crops both trail supervised, motivating a mix. — [arXiv 2112.00319 (HTML)](https://arxiv.org/html/2112.00319v1); [v1 PDF](https://arxiv.org/pdf/2112.00319v1)
- Purushwalkam & Gupta: MoCo-v2 on MSCOCO GT object crops only vs full images: VOC full-image linear 59.6 vs 64.39 (box-only WORSE by 4.8), VOC cropped-boxes linear 75.29 vs 71.94 (box-only BETTER by 3.35), ImageNet 34.24 vs 33.64; authors attribute the full-image loss to VOC's co-occurrence/background cues and the cropped-box gain to stronger object discrimination. — [ar5iv 2007.13916](https://ar5iv.labs.arxiv.org/html/2007.13916)
- SGCL builds ALL positive pairs from saliency regions (random crops only for initialisation) and beats BYOL/ORL on COCO det (40.7 vs 39.5/40.3) and IN linear (59.9 vs 57.8/59.0). — [ar5iv 2302.11461](https://ar5iv.labs.arxiv.org/html/2302.11461)
- Two Global Crops Suffice (ViT-L, 2026): DINOv1 2G+8L kNN 79.1 / Sem-PCK 32.0 vs 2G-only 72.4 / 31.2; DINO 1G+8L (globals replaced by locals) 47.0 kNN / 10.6 Sem / 58.8 Geom; "Local crops are not the source of semantic structure"; locals add view diversity for classification. — [arXiv 2609.28187](https://arxiv.org/html/2609.28187v1)
- DINO Table 8: dropping local crops costs 6.8 linear points at 100 ep (74.6 -> 67.8). — [ar5iv 2104.14294](https://ar5iv.labs.arxiv.org/html/2104.14294)
- DenseDINO: adding 4x96 locals to 2x224 globals raises kNN 53.3 -> 58.8 but lowers VOC linear seg 46.0 -> 39.7. — [ar5iv 2306.04654](https://ar5iv.labs.arxiv.org/html/2306.04654)
- ODIS (2025): global views are kept and the best object representations come from random context-rich local crops, not object-aware windows. — [arXiv 2506.05409](https://arxiv.org/html/2506.05409)
- SoCo keeps the whole image as V1 and its "whole image" ablation baseline (38.1/34.4 APbb/APmk) is 3.5 AP below the object-level objective with scale-aware assignment. — [ar5iv 2106.02637](https://ar5iv.labs.arxiv.org/html/2106.02637)

### Inferences
- The closest precedent to "object-only views transfer better to object chips, and keeping scene views loses the gain" is Purushwalkam & Gupta 2020 (box-only pretraining +3.35 on cropped-box eval, -4.8 on full-image eval), but it used ground-truth boxes, MoCo-v2, ResNet-50, no SSL on scene views at all, and no mixed condition. Coarse-Is-Better is the only label-free precedent for training exclusively on crops with CNNs, and it did not test an "object + whole-scene" mixed condition either.
- The ViT/DINO literature (Two Global Crops, DenseDINO) argues that whole-image views carry the semantic/correspondence signal and small crops only add diversity; this is the main counter-evidence a reviewer would raise, so our finding that whole-scene views HURT on SAR needs to be framed as task- and domain-specific (object chips, scene-centric SAR).

### Gaps
- No paper found that tests all three conditions (object-only, scene-only, object+scene mixed) with a CNN on a cross-dataset object-chip task; Mishra tests Obj-Obj vs Obj-Scene but on the same datasets (OpenImages/COCO/VOC).

## KQ4. Did any paper separate "crop size" from "crop placement" with explicit controls the way we did?

### Takeaway
Not found as a full factorial; the nearest controls are SoCo's random-box ablation (random boxes K=1: 41.4 vs selective search 41.6 APbb, with random boxes diverging at K >= 4), Coarse-Is-Better's Grid-Crop / random-box / Poor-Crop / GT-Crop ladder (random boxes 39.1 vs objectness crops 40.2 vs whole image 38.8 COCO APbb), UniVIP's "naive" boxes (58.9 vs 60.2 IN top-1), and ContrastiveCrop whose design changes ONLY the crop centre while keeping RandomCrop's scale sampling (k=0 and alpha=1 as controls). Mishra, CAST, ORL, InsLoc, SGCL, Odin, DetCon (text), SelfPatch, Leopart and ODIS report no same-size random-placement control.

### Cited Findings
- SoCo: "random boxes instead of selective search" K=1 41.4/36.9 APbb/APmk vs selective search K=1 41.6/37.3 (default K=4 42.3/37.6); random K=4 and K=8 diverged (NaN). Box size distribution of random boxes vs proposals is not stated to be matched. — [ar5iv 2106.02637](https://ar5iv.labs.arxiv.org/html/2106.02637)
- Coarse Is Better?: VOC pretraining (BYOL) Grid-Crop (fixed grid, objectness 39.8 %) 68.1 AP50 vs Our-Crop 69.5 vs GT 66.9 vs Poor-Crop 60.4 vs Image-Crop 63.3; COCO random boxes 39.1/35.5 vs Our-Crop 40.2/36.4 vs Image-Crop 38.8/35.0; the authors frame objectness (not size) as the driver and do not match crop sizes explicitly. — [ar5iv 2306.04244](https://ar5iv.labs.arxiv.org/html/2306.04244)
- UniVIP: "naive" box generation 58.9 IN top-1 / 40.5 COCO mAP vs selective search 60.2 / 40.8 vs no instance views 57.7 / 39.6; no pure random-box row. — [ar5iv 2203.06965](https://ar5iv.labs.arxiv.org/html/2203.06965)
- ContrastiveCrop: the same scale s and ratio r as RandomCrop are reused, only the centre is moved into the activation box (k) with Beta(alpha) sampling; k=0 recovers RandomCrop; alpha=1 recovers uniform placement inside the box; localization alone beats RandomCrop for k in ~0.05-0.2 and degrades above 0.25 (curve in Fig. 6a); update-frequency ablation 0 % 63.43, 20 % 64.61. — [ar5iv 2202.03278](https://ar5iv.labs.arxiv.org/html/2202.03278)
- CAST: only phi=0 (unconstrained) vs phi=0.2; "not a size-matched random-placement control". — [ar5iv 2012.04630](https://ar5iv.labs.arxiv.org/html/2012.04630)
- Object-Aware Cropping: "The paper does not report" a random-box control; baselines are scene crops and proposal variants; Obj-Obj+Shift (proposal shifted) 54.1 vs Obj-Obj+Dilate 58.6 is the nearest placement perturbation. — [arXiv 2112.00319 (HTML)](https://arxiv.org/html/2112.00319v1)
- ORL: no random-box ablation; GT boxes 85.4 vs selective search 86.7. — [ar5iv 2106.11952](https://ar5iv.labs.arxiv.org/html/2106.11952)
- InsLoc: no ablation isolating foreground size or placement. — [ar5iv 2102.08318](https://ar5iv.labs.arxiv.org/html/2102.08318)
- SGCL: no labelled random-crop control; selective search 80.3 vs own saliency 83.2 vs GT 84.7 (VOC07, 100 ep). — [ar5iv 2302.11461](https://ar5iv.labs.arxiv.org/html/2302.11461)
- DetCon: spatial grids (2x2/5x5/10x10) tested as content-free masks (5x5 best; numbers only in Fig. 7); Odin: no random-mask control. — [ar5iv 2103.10957](https://ar5iv.labs.arxiv.org/html/2103.10957); [ar5iv 2203.08777](https://ar5iv.labs.arxiv.org/html/2203.08777)
- Chin et al. masking: saliency-off (random) vs saliency-on masking differs by only +0.01 to +1.06 on TinyImageNet, i.e. a placement control showing most of the gain is NOT from placement. — [ar5iv 2309.12757](https://ar5iv.labs.arxiv.org/html/2309.12757)
- Jha & Tuytelaars 2024: explicitly "does not separate crop size from placement". — [arXiv 2409.18228](https://arxiv.org/html/2409.18228)
- Two Global Crops Suffice: "does not vary local-crop scale or placement separately". — [arXiv 2609.28187](https://arxiv.org/html/2609.28187v1)

### Inferences
- A size-matched random-window control that explains PART of the object-crop gain is consistent with what the few existing controls show (SoCo random K=1 within 0.2 AP of proposals; Coarse-Is-Better random/grid boxes capturing roughly a third to two thirds of the gain; Chin et al. masking gain mostly from masking itself). Our explicit "same crop sizes, random placement" control therefore agrees with the literature's direction and is more explicit than any of the published ones.
- No published study reports that placement matters only for one downstream task (object chips) and not for same-dataset detection; the Purushwalkam full-image vs cropped-box asymmetry is the only analogous task-dependence found.

### Gaps
- Not found: a paper with a 2x2 (size x placement) design, or one that reports the fraction of the object-crop gain recovered by random same-size windows. Queries tried: "self-supervised learning crop placement vs crop size disentangle control random crops same size object crops transfer 2024"; "random crop vs object proposal crop control self-supervised ablation random boxes"; "saliency-guided cropping self-supervised contrastive learning".

## KQ5. Are there papers on object-centric SSL for LIGHTWEIGHT CNNs (MobileNet, EfficientNet) rather than ResNet-50 / ViT?

### Takeaway
Not found: every crop-placement paper above uses ResNet-50 (or ViT-S/B/L); the lightweight-backbone SSL literature (SEED, DisCo, BINGO, RoB, Tan et al. ICLR 2023, Self-EMD's MobileNetV2 row) uses standard random crops and mostly distillation, and the 2024 detection-SSL survey discusses no MobileNet results. The only MobileNetV2 object-detection SSL numbers found are Self-EMD (27.1 AP vs BYOL 26.0 vs supervised 29.3, COCO pretraining) and Tan et al. (32.1/29.1 vs DINO 30.9/28.1 vs supervised 33.1/29.8), and in both the small SSL model still trails supervised ImageNet.

### Cited Findings
- Self-EMD, MobileNetV2, COCO pretraining, COCO val AP: supervised ImageNet 29.3, BYOL 26.0, Self-EMD 27.1; "the overall performance of self-supervised models are inferior to the supervised pre-training" for the small model. — [ar5iv 2011.13677](https://ar5iv.labs.arxiv.org/html/2011.13677)
- Tan, Saleh, Martinez (ICLR 2023), MobileNetV2 Mask R-CNN FPN COCO 1x: their method 32.1 APbb / 29.1 APmk vs DINO 30.9/28.1 vs supervised 33.1/29.8 (Table 6); vs SimReg 32.4/29.3 vs 30.7/27.7 (Table 11, different values for the same setting); ResNet-18 1x: SEED 34.7, DisCo 34.6, theirs 34.7 APbb. - DisCo (Gao et al., ECCV 2022): students EfficientNet-B0/B1, MobileNet-v3-Large, ResNet-18/34 distilled from ResNet-50/101/152 teachers; plain MoCo-v2 on MobileNet-v3-Large reaches only 36.2 IN top-1 vs DisCo 64.4 (R-50 teacher); detection reported only for ResNet-34 (VOC AP MoCo-v2 53.6 -> DisCo 56.5; COCO 38.1 -> 40.0); views unchanged. — [ar5iv 2104.09124](https://ar5iv.labs.arxiv.org/html/2104.09124)

BINGO and CompRess full texts were not fetched (they are distillation methods with standard views, per DisCo and Tan et al.).
